# Insta Carousel Prompt Generator V2

Static carousel prompt studio for creating Instagram carousel image prompts, caption prompts, ready captions, CTA copy, and DM automation flows.

## Project files

- `index.html` — main static page.
- `src/styles.css` — app styling.
- `src/app.js` — app logic.
- `standalone.html` — self-contained single-file version.
- `QA_REPORT.md` — test notes.

## QA completed

Tested with browser automation for initial render, tab navigation, live preview updates, theme sync, font controls, color controls, slide editing, add/delete slide, drag positioning, save/load fallback, output generation, and mobile layout.
